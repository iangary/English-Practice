# The Daily Minimum (read this if you haven't logged anything yet)

It's been 22 days since this program was built and `PROGRESS_LOG.md` is
still empty. Not one baseline score. Not one drill. That's not a vocab
problem or a content problem — the program has plenty of material sitting
unused in `GRE/`, `IELTS/`, and `TOEFL/`. It's a starting problem.

The 10-week plan in `STUDY_PLAN.md` asks for 90-120 minutes/day. If that's
the barrier, stop trying to start there. Start here instead.

## The 12-minute version

No excuse survives this. Do it today, log it in `PROGRESS_LOG.md`'s Drill
log table the moment you finish (not later — later is how 22 days become
60), and come back tomorrow for the next one.

1. **Set a timer for 10 minutes.** Not a vibe — an actual timer.
2. Pick ONE:
   - 10 GRE words from `GRE/verbal_vocab.md`, drilled word→meaning AND
     meaning→word.
   - One GRE Text Completion set (single, not the whole file) from
     `GRE/text_completion_practice.md`, timed.
   - One IELTS Speaking cue card from `IELTS/speaking_cue_cards.md` —
     talk out loud for 2 minutes, no notes.
3. **Stop at 10 minutes**, whether or not you're done. Pacing under a
   deadline is the actual skill being tested on exam day — don't train
   yourself out of it by running over.
4. **2 minutes:** log it. Date, what you did, how it went, one sentence
   on what went wrong. That's the whole row.

## Why this exists

A coach's job isn't to hand you more pages — you have 50KB of drills
already and haven't opened the log once. It's to make the next session
unskippable. 12 minutes has no good excuse. 90 minutes does.

Once you've logged 3 sessions in a row, delete this file and go run the
real plan in `STUDY_PLAN.md`. You don't need training wheels after that —
you need the volume.
