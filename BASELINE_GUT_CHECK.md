# The Baseline Gut-Check (Week 0 — Do This Before Anything Else)

**Status check on this repo: `PROGRESS_LOG.md` has zero entries.** Every
table — baseline, drill log, weekly mock, recurring mistakes, vocab
mastery — is still empty. `STUDY_PLAN.md` is explicit that Week 0 is a
hard prerequisite: "No studying 'around' this — if you don't know your
baseline, every later number is meaningless." Whatever got built so far
in this repo hasn't been *used* yet. This file exists to force the issue.

This is not a new, softer on-ramp. It's the Week 0 baseline from
`STUDY_PLAN.md`, assembled into one sitting, with the volume turned up:
four sections back-to-back, the way fatigue actually stacks on real test
day. No section is new material — all of it pulls from drills already in
this repo — but you've never done them in sequence, under a combined
clock, which is harder than doing any one of them fresh.

## Rules

- **One sitting. ~89 minutes of pure working time.** Phone away, single
  timer, no pausing between sections (a 2-minute water break between
  sections is allowed; it is not a 10-minute break).
- **Do the sections in this order** — it's deliberately front-loaded with
  the two sections most people avoid:
  1. GRE Quant Drill Set — 21 minutes (`GRE/quant_drills.md`, all 12
     questions)
  2. GRE Text Completion & Sentence Equivalence — 10 minutes
     (`GRE/text_completion_practice.md`, all 10 questions)
  3. TOEFL Reading Passage 1 — 18 minutes (`TOEFL/reading_practice_01.md`)
  4. IELTS Writing Task 2 — 40 minutes (`IELTS/writing_task2.md`, prompt
     #3 — salary gap — don't cherry-pick an easier prompt)
- **Grade immediately, same sitting, before you eat/leave/check your
  phone.** Use each file's own answer key and self-grading rubric. Scores
  fade from memory fast and get rationalized if you wait.
- **Log every section's result in `PROGRESS_LOG.md`'s Baseline (Week 0)
  table right now** — exam/section, score, time taken, and one honest
  sentence per section on what specifically went wrong. "I need to
  review more" is not an acceptable entry; "ran out of time on Q11-12
  because I didn't skip the probability question I was stuck on" is.

## Scoring — what "passing" Week 0 actually means

Week 0 isn't pass/fail on absolute score. It's pass/fail on whether you
now have **real numbers** instead of a guess. You pass Week 0 when:

- All four sections are timed (not estimated afterward) and scored
  against the real answer key/rubric, not vibes.
- All four rows exist in `PROGRESS_LOG.md`, filled in, today.
- You've identified, in writing, your single weakest section of the
  four — that's the one `STUDY_PLAN.md` Weeks 5–6 tells you to double
  down on later, so losing this answer now costs you precision then.

If your score on any section is well below the targets in the main
`README.md` (IELTS 7.5+, TOEFL 105+/24+ per section, GRE V162+/Q165+/AWA
5.0+) — good. That's what a baseline is *for*. A baseline you're already
happy with isn't a baseline, it's a victory lap you gave yourself early.

## After this

Once this is logged, start Week 1 of `STUDY_PLAN.md` tomorrow — not
today. You just did ~90 minutes of exam-condition work; doing Week 1's
daily vocab and Mon/Wed/Fri essay on top of this same day is how people
front-load burnout in week one and quit by week three. Rest, review your
wrong answers once more before bed, start the schedule fresh.
