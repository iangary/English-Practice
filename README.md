# English-Practice

An intensive, self-paced training ground for three high-stakes English exams:
**IELTS**, **TOEFL iBT**, and the **GRE** (verbal + quant + AWA).

This repo is run like a training camp, not a textbook. Nothing in here is
decorative — every file is something you do, time, score, and log. If a
file doesn't have a timer attached to it, it's not a drill, it's trivia.

## How this is organized

| Folder | Contents |
|---|---|
| `STUDY_PLAN.md` | The 10-week schedule. Start here. |
| `PROGRESS_LOG.md` | Your scorecard. Fill it in after every drill — no exceptions. |
| `GAUNTLET.md` | Cross-exam stress session, once technique is solid in each skill. |
| `IELTS/` | Writing Task 2, Academic Reading (2 passages), Speaking cue cards, vocabulary |
| `TOEFL/` | Independent + Integrated Writing, Reading (2 passages), Speaking tasks |
| `GRE/` | Verbal vocab (2 sets), Text Completion (2 sets), Reading Comprehension (2 passages), Quant drills (2 sets), AWA |

Every drill file above now has a **Set 2 / Advanced tier** section once
you clear Set 1 at a solid pace — don't start Set 2 material until Set 1
is genuinely automatic, and don't stay on Set 1 past that point either.
Progressive overload, not comfort, is the point of a training camp.

## Rules of engagement

1. **Always time yourself.** Use a real timer, not a vibe. Untimed practice
   is the single biggest reason people plateau — it hides the pacing
   problem that actually fails them on test day.
2. **Score honestly, then log it.** `PROGRESS_LOG.md` only works if the
   numbers are real. A fudged score is a lie you tell your own test date.
3. **No skipping the weak skill.** If you dread the Quant drills or the
   Speaking cue cards, that's the signal you need them most — do those
   first, not last.
4. **Review > volume.** After every drill, spend as long reviewing your
   wrong answers (and *why* they're wrong) as you spent doing the drill.
   Redoing the same mistake faster is not progress.
5. **Weekly mock, no excuses.** Every week ends with a full timed section
   under exam conditions (phone away, no pausing). See `STUDY_PLAN.md`.

## Target bands/scores (adjust once you know your baseline)

- **IELTS:** Overall 7.5+ (no band below 7.0)
- **TOEFL iBT:** 105+ (no section below 24)
- **GRE:** Verbal 162+, Quant 165+, AWA 5.0+

Push for these numbers, not "pretty good." Coaches don't grade on effort —
neither do admissions committees.
