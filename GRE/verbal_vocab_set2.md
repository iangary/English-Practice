# GRE Verbal — High-Frequency Vocabulary, Set 2 (30 words, harder tier)

**Prerequisite:** Don't start this set until every word in `verbal_vocab.md`
(Set 1) passes the "under 3 seconds, both directions, two days running"
bar. This set assumes Set 1 is automatic — several definitions below are
written in terms of Set 1 words, deliberately, to force cumulative recall
instead of treating each set as an isolated island.

**Drill protocol:** Same as Set 1 — word → meaning, then meaning → word,
both directions timed. Additionally: once a word is "known," write your
own example sentence (not the one below) in `PROGRESS_LOG.md`'s vocab
table notes — recognizing a word in a sentence someone else wrote is
easier than generating one, and the real test requires the harder skill.

## Cumulative drill: Set 1 + Set 2 mixed (fill in the blank)

Cover the answer key. These deliberately mix both sets — the real GRE
does not sort questions by which "set" you learned a word in.

1. The negotiator refused to ______ (deny) the leaked terms, which
   everyone took as a tacit confirmation.
2. His reasoning was ______ (superficially plausible but wrong) at best
   and outright ______ (lying) at worst.
3. The CEO's ______ (excessively eager to please) response to every
   board question made several directors visibly uncomfortable.
4. A government that governs by appealing to fear rather than argument
   risks being remembered as led by a ______.
5. The scandal earned the firm widespread ______ (harsh public
   criticism), a sharp reversal from the ______ (approval) it enjoyed
   just a year earlier.

### Answer key
1. gainsay
2. specious; mendacious
3. obsequious
4. demagogue
5. opprobrium; approbation

## Why mixing sets matters

GRE Verbal never tells you which "unit" a question's vocabulary came
from — a Sentence Equivalence question might require a Set 1 word and a
Set 2 word to both click in the same five seconds. If you can only
produce a word when it's presented in the list it was taught in, you
have memorized a list, not learned a word. Re-run Set 1's drill cold
once a week for as long as you're actively working through Set 2, so the
two sets stay merged into one retrievable vocabulary rather than two
separate ones.
