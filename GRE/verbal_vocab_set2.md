# GRE Verbal — High-Frequency Vocabulary, Set 2 (30 words, harder tier)

**Prerequisite: do not start this set until Set 1
(`verbal_vocab.md`) is logged as mastered in `PROGRESS_LOG.md`** — both
directions, under 3 seconds each, correct twice on different days. Rushing
ahead to feel like you're "covering more words" is exactly how people end
up with 300 words they half-know instead of 150 they actually own.

**Drill protocol:** same as Set 1 — word → meaning, then meaning → word.
These words are harder than Set 1 specifically because they're more
easily confused with each other (near-synonyms with different shades of
meaning) or because test-writers favor them precisely for their
ambiguity in context.

## Drill: near-synonym discrimination (the actual GRE trap)

These pairs/groups are commonly confused. Write one sentence for each word
that would make the OTHER word in the pair clearly wrong in that slot.

1. **Glib** vs. **Erudite** — both can describe someone who talks well;
   one implies hollow fluency, the other implies real depth.
2. **Contrite** vs. **Sanctimonious** — both involve a moral stance after
   wrongdoing; one is genuine, one is performative and often directed at
   someone else's wrongdoing instead.
3. **Perfunctory** vs. **Punctilious** — near-opposite attitudes toward
   detail and effort, easy to swap under time pressure.
4. **Inchoate** vs. **Recondite** — neither means "hard to understand" the
   way test-takers often misremember; one means "unformed," the other
   means "obscure/known to few."

### Answer key (self-check, not a fill-in-the-blank this time)
If you could clearly state *why* the other word fails in each sentence you
wrote, you've learned the distinction. If you had to guess, you've learned
the word in isolation but not the distinction the GRE actually tests —
go back to the definitions above before moving on.

## Why this set is harder than Set 1

Set 1 words mostly fail you through unfamiliarity — you either know
"ubiquitous" or you don't. Set 2 words fail you through **confusability**:
you'll recognize all of them, but under time pressure you'll reach for the
near-synonym that's wrong for the sentence's specific shade of meaning.
That's precisely the skill Sentence Equivalence tests, where two answer
choices are both plausible-sounding synonyms but only one pair creates
the exact same sentence meaning.
