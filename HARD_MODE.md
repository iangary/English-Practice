# Hard Mode — Overlay Rules

Read this if you've asked to be "pushed to the limit." It doesn't replace
`STUDY_PLAN.md`; it tightens it.

## What changes under hard mode

1. **Timing tightens by ~15-20%.** Where Set 1 material says 1:45/question
   or 40 minutes, the Set 2 / hard-mode files in each folder
   (`GRE/verbal_vocab_set2.md`, `GRE/quant_drills_set2.md`,
   `IELTS/writing_task2_band9_benchmarks.md`,
   `TOEFL/speaking_tasks_hard_mode.md`) cut that further. Don't skip to
   these before clearing the Set 1 material at full accuracy — hard mode
   on an unstable foundation just trains panic, not skill.
2. **Target scores go up, not down.** Treat the numbers in `README.md`
   as the *floor*, not the goal: IELTS 8.0+, TOEFL 110+, GRE V165/Q168+.
   Aim past the admissions bar, because test-day nerves cost real points
   you don't get to practice away.
3. **No score gets accepted without a logged root cause.** "I got a 6.5"
   is not a log entry, it's a non-answer. Every logged score needs the
   specific mechanism of every lost point: mistimed, misread the
   question, didn't know the word, second-guessed a correct answer. A
   score without a cause can't be fixed next time.
4. **Missed sessions compound, they don't reset.** If you skip a planned
   session, it does not disappear from the schedule — it gets added to
   the next session's load. The 10-week plan assumes 6 days/week; a
   missed day is paid back, not forgiven, because the real exam date
   doesn't move either.
5. **Weekly mock is non-negotiable and the first thing graded harshly.**
   Self-grading Task Response/Delivery/Topic Development leniently is
   the most common way people quietly protect their own motivation at
   the cost of an accurate signal. Use the harsher rubrics in the
   hard-mode files, which spell out exactly what separates a generously-
   scored Band 7/TOEFL 24 from the real thing.
