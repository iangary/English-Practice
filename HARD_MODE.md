# Hard Mode — Escalation Protocol

The base drills in `IELTS/`, `TOEFL/`, and `GRE/` get you to a competent
score. They will not, by themselves, get you to the top of the band/score
range. This file is the bridge between "I can do this" and "I can do this
under worse conditions than the real test will ever give me" — which is
the only reliable way to have margin left on test day.

## The rule: earn hard mode, don't default to it

Each exam area now has one or more `*_hard.md` files alongside the base
drills. Each has an explicit unlock condition at the top. **Do not skip
to the hard file because the base file feels easy on a good day.**
Plateauing happens in both directions: grinding material you've already
mastered wastes time, and jumping to material you haven't earned trains
panic instead of skill, because you fail for reasons that have nothing to
do with the actual gap (word-pair confusion, a formula you half-know,
pacing you've never built). Either way you get bad data in
`PROGRESS_LOG.md` and draw the wrong conclusion about what to fix.

| Base file | Hard-tier file | Unlock condition |
|---|---|---|
| `GRE/verbal_vocab.md` | `GRE/verbal_vocab_hard.md` | Both directions, <3s each, 2x on different days |
| `GRE/quant_drills.md` | `GRE/quant_drills_hard.md` | 11–12/12 on the base set |
| `IELTS/writing_task2.md` | `IELTS/writing_task2_hard.md` | Consistent self-graded 7.0+ |
| `TOEFL/writing_tasks.md` | `TOEFL/integrated_writing_hard.md` | Reliably catching all claim/counterpoint pairs |

## What "hard mode" actually changes, by design

1. **Less time, not more content.** GRE Quant hard tier: 1:30/question
   instead of 1:45. IELTS Writing hard tier: 32 minutes instead of 40.
   This is the single highest-leverage lever — a skill you can execute
   at 80% of the real time limit gives you a buffer for the inevitable
   bad day (tired, distracted, a genuinely hard prompt) at test time.
2. **Denser, messier source material.** The TOEFL hard-tier Integrated
   Writing task uses counterpoints that are worded completely differently
   from the reading claims they attack (e.g., "Lucas paradox" instead of
   restating "capital flows the wrong way"). Real test material gets this
   messy at the harder end of the scoring range — recognizing a
   restated idea under a new label is itself the skill being tested.
3. **Lower-frequency, more confusable vocabulary.** GRE hard-tier words
   are chosen because they're easy to mix up with a *different* word that
   means something similar-but-distinct. When you self-grade, log which
   other word you almost confused it with — that pairing, not the single
   word, is what you actually need to drill.
4. **Two-barreled, abstract prompts.** IELTS hard-tier prompts are
   deliberately harder to summarize in one clean sentence. If your thesis
   sentence takes you more than two tries to write cleanly, that's useful
   signal — it means the base-tier prompts weren't forcing you to handle
   genuine conceptual tension.

## Standing rule

Every time you clear a hard-tier unlock condition, say so explicitly in
`PROGRESS_LOG.md` (date + which file) before starting that hard set — not
after. This turns "I think I'm ready" into a dated, checkable claim you
can hold yourself to, instead of a vibe you can quietly lower later.

If you clear a hard-tier set at the top of its scoring band on your first
attempt, that's a signal the gap between base and hard tier wasn't big
enough for you specifically — note it in `PROGRESS_LOG.md`'s recurring
mistake tracker as a "ceiling too low" entry, and the next session should
tighten the timer further rather than declare victory.
